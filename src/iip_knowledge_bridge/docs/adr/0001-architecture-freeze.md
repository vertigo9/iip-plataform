# ADR-0001: Architecture Freeze v1.0

**Status:** ACCEPTED
**Date:** 2026-07-18
**Authors:** IIP Team

## Context

The IIP Platform architecture has been designed through multiple iterations.
To ensure focused delivery for v1.0, we need to freeze the architecture scope.

## Decision

No new modules or architectural changes during v1.0 implementation.
All new ideas go to Backlog v1.1 for evaluation.

## Consequences

- Focused delivery on core functionality
- Reduced scope creep risk
- New features wait for v1.1 evaluation
- Clear completion criteria for v1.0
