# ADR-0002: Python 3.13+ Requirement

**Status:** ACCEPTED
**Date:** 2026-07-17
**Authors:** IIP Team

## Context

Modern Python features improve type safety, performance, and developer productivity.
The platform requires strong typing for financial calculations.

## Decision

Require Python 3.13 or higher as minimum version.

## Consequences

- Access to latest type hint improvements
- Better error messages from modern interpreters
- Users must upgrade if on older Python versions
